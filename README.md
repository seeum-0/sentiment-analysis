
# Sentiment Analysis Web App

A web application that performs sentiment analysis using a Hugging Face transformer model. Built with Python, Flask, HTML, Tailwind CSS, and JavaScript.

## Setup

### 1. Clone the Repository

```bash
git clone https://github.com/seeum-0/sentiment-analysis.git
cd sentiment-analysis
```

### 2. One-Time Setup

Double-click `setup.bat` to install the required dependencies.

### 3. Run the Application

Double-click `run.bat` to start the server.

### 4. Open in Browser

Navigate to http://127.0.0.1:5000

---

## How It Works

Enter a word, sentence, or paragraph into the input field. The application uses a Hugging Face transformer model to classify the sentiment as either **POSITIVE** or **NEGATIVE**, along with a confidence score.

## Example

**Input:** `I love this project!`

**Output:** `POSITIVE (0.999)`

## Requirements

- Windows 10/11
- Python 3
- Internet connection for initial setup
